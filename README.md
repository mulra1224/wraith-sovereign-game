# 망령군주: 잿빛섬 — First Playable v0.1

옛 2D MMORPG의 간결한 사냥 리듬을 새로운 세계관과 그래픽으로 재해석한 Android 오프라인 싱글 RPG 프로토타입입니다. 리니지 원본 리소스는 포함하지 않습니다.

## v0.1 플레이 루프

- 화면 터치 이동, 몬스터 터치 자동 평타
- 슬라임·고블린·오크·해골·구울 사냥
- 경험치, 레벨업, 주화와 드랍
- 무기 강화 및 체력 물약
- 레벨 3 데스나이트 변신과 공격속도 상승
- 바포메트 필드 보스
- 독립적으로 사냥하고 성장하는 AI 모험가 3명
- 사망 페널티, 마을 부활, 로컬 저장

## APK 받기

GitHub의 **Actions → Build verified Android APK → 성공한 실행 → Artifacts**에서 `wraith-sovereign-android-debug`를 내려받아 압축을 풀고 APK를 설치합니다.

Android에서 차단될 경우 설정에서 브라우저 또는 파일 앱의 **출처를 알 수 없는 앱 설치**를 일시적으로 허용해야 합니다. 이 APK는 테스트용 디버그 서명입니다.

## 개발 실행

Godot 4.3 이상에서 `project.godot`을 열고 `F6/F5`로 실행합니다. PC에서는 WASD 또는 마우스로 이동할 수 있습니다.
